# shell map

The map's model, the modal, the minimap and their parts: `Maps`, `MapView`, `Board`, `Stage`, `Sidebar`, `Card`, `LiveMap`. The `Tracker` and the `Run` they follow are `run`'s.

## Surface
- `Maps`: the open game's offers (its record's, then the linked or matched title's), the chosen one, its load and the runs both boards follow; `is_open`, `mapped`, `live_map`, `set_minimap` (the overlay's docking command). `open`, `close`, `choose` are `MapView`'s, `refresh` the sidebar's REFRESH. Emits `MapsEvent::Retile`.
- `Titles`: every source's titles in the content locale and the titled sources' names, made by `Maps`; `ready` once the disk copies are read; `refresh`.
- `MapView`: the modal's window parts (`show`, `hide`, `set_docked`) and `linker`, the LINK A MAP dialog (`TitlePicker`) `Root` draws while open, over the map; the panel opens it for a game without maps, the toolbar's LINK A MAP for any game while a source has titles or one has none yet (`Titles::pending`: the picker asks it; not in a dock); UNLINK MAP stands beside LINK A MAP (toolbar and empty panel) while the open game has a link set by hand, and drops it (`Library::unlink`: the offers are gathered again, so a store-id match or nothing takes its place); emits `MapEvent::Close`. `map_panel` is the page's preview that opens it, `paneled` whether the page shows it.
- `Minimap`: a mini `Stage` over the live board, one per window; `hide(window)` lets go of its tiles.
- `LiveMap`: the live game's map for the minimap.
- `Tracker` (`run/`): one per live run whose trainer can place the player; `Runs` makes it. As Wand's: a fix needs the leaseholder's plane axes, a height not told is 0.
- `bind_keys`.

## Rules
- `Maps` follows `RunEvent`s itself: the open map gets the run of its game, the minimap the live run while its dock is shown. `map` never names the overlay.
- `Maps` gathers the offers on every `LibraryEvent`, `TitlesEvent` and language change, and asks a source again only when the game, the title or the locale changed; the task is replaced, so nothing of another game lands. A link wins over a match unless its source is not there; a game with maps of its own takes a link only, never a match. A game is matched only once `Titles` is `ready` in the content locale; one without maps or a title asks `Titles::refresh` once per game and locale, and again when a titled source comes or is replaced. A new locale keeps the title's offers until theirs arrive. The chosen map is kept by `Ref`; gone or in a new revision, an open one loads again, a closed one at its next `open` (`held`: the map and revision asked for). A map whose offers are withdrawn while open closes: the modal by `MapView`, the dock by `Hud`, which takes the focus back.
- On `SourcesChanged`: `Titles` drops a gone source's titles and reads the disk copies again (before `Maps` gathers); `Maps` asks a replaced source again for the title's offers (kept until they come) and drops a gone one's; the board's map of a changed source loads again when open and still there, else the board saves and lets go of its copy and `MapsEvent::Retile` drops the stage's tiles at once.
- `Titles` reads the disk copies alone (it takes `Cached` and drops the stream: no call) at start and on a language change; `refresh` (the picker opening, a game without a title) goes past them, so a source calls only when its copy is stale. The picker orders by `likeness`, shows each title's source by name and never links by itself.
- The minimap follows a record's maps only: a discovered map has no `Frame`.
- REFRESH: `Registry::refresh` marks the copy stale, `media::forget_missing` drops the map's absent tiles on disk, `MapsEvent::Retile` the stage's, then the map is asked again as `_load`, which a choice or a language change drops.
- The camera is the stage's: `Maps` reads it through `set_camera` and keeps it on the board before the board lets go of the map (`close`, `choose`).
- Each part is its own entity drawn with `cached`, observing the shared `Board`. The board notifies on what a person does, never per frame; the player's moves are `BoardEvent::Moved`, which only the stage hears.
- `Board::live` (the minimap's) never writes the user's state: `saves` is off and it adopts the big board's `Rc<Saved>`. Only the big board writes (`Board::save` flushes what changed); either board's first load of a map may take over its older file.
- Map state is written blocking, on each change, in order. The user's pins are addressed by id (`Board::mark`, the stage's hover, the sidebar's commands), never by index; a deleted one stays as a tombstone that `Saved::pins` skips. A board saves before it swaps or closes a map (`pending`, `hide`); `forget` does not save. The state and heading are `client::map`.
- `Tracker` asks the position only while a `Lease` is held, one question at a time. The board holds its lease (`_fixes`) only while open with a tracker and a map that has a `Frame`; dropping it stops the asking.
- Snapshots reach a board through `board::show`: a `Cached` one is skipped when the board already holds a shared copy.
- A board keeps the map and locale it asked for (`asked`); a copy is shared or reused only between the same two. A board that takes the other's copy before that board's load is done (`settled`) loads its own too. Another content language: the open map loads again through `choose`, a closed one lets go of its copy, and the minimap's search starts over (`Maps::relocalize`).
- Tiles, icon sheets and clips load through `client::media` (`tile`, `load`, `path`).
- A tile is asked only when `Tiles::covers` it; stand-ins go down to `min_zoom`. A view asks for its backdrop (`BACKDROP` levels up, kept while it covers the view) first, then its own tiles from the middle out; a zoom asks for the view its glide ends at, a followed player for the view on its last fix. The stage's load is `media::tile` then `art::picture`: `Absent` for a 403, 404 or 410 (kept on disk) or bytes that are no WebP, PNG or JPEG within its side (not asked again while the map shows) or `Retry` (asked again on a draw after a wait doubling from 1 s to 64 s; no timer).
- The chosen tile set is `View::tile_set`, changed through `Board::filter`; the stage drops its tiles when the set it draws changes.
- TELEPORT HEIGHT is the game's (`GameProfile::teleport_lift`, set by `Maps::set_lift` through `Trainers`, no `TrainerEvent`); `Maps` gives the open game's to the board (`Board::set_lift`) when the game changes and on a set. `Board::teleport` (a pin's, a plane point's at the player's height) adds it (`Frame::raised`); `teleport_to_mark` decides a user's pin: one with a `UserPin::position` (the stage's pin control, shown only while `Board::here`: a current fix whose height the trainer told) goes there exactly, without it. The sidebar's field shows while the map teleports, in game units, kept as typed (a CONFIRM click leaves it focused); not in the stage, whose keys take `-` and the arrows. A board change that drops its row moves the focus to the search.
- While `Board::here` and `View::rises` (HEIGHTS NEARBY, offered only then), a pin or a user's pin with a game position near the player shows under its tip how far above or below them it is, in game units (`stage/rise.rs`); its texts are kept per value in `Shown`.
- The minimap groups close pins only with `View::mini_clusters` too, offered under GROUP CLOSE PINS for a map with a `Frame`.
- A map's pin the user hid (the card's HIDE: its place is gone) never shows, not even to a search, and leaves its group's count; MOVE (`Board::clone_pin`) copies it into the user's pins and hides it, and the copy stands in for it: its FOUND is the original's and the original counts. HIDE closes the pin's card; HIDDEN PINS in the sidebar opens a hidden pin (a selected pin always shows), whose card shows it again. The counts are `Saved::tally`, made again on each of these (`Board::recount`).
- A user's pin moves only on a drag with Alt held from its head (a double click there moves it too, no zoom): its tip keeps its offset from the cursor on the view, under a moving camera too, the marker and its height drawn there; the release point is kept (`Board::move_mark`); a game position keeps its height. Its height changes only by the X Y Z typed on its card (a map with a `Frame`; without a game position it shows its plane point at 0), kept on Enter, blur, the card closing or showing another mark, or the map closing, on the map and pin they were typed for (`Card::axes_for`, a `Target`; `Board::place_mark`); either emits `BoardEvent::MarkMoved`, which refills them.
- Picture icons are cut once per copy of a map (`Icons`, made at `install`, a sheet at a time; dropped with the last board holding the copy, it fetches no more) and travel with it to a board that takes the copy (`Shared`); views make device-sized images of them in `Images`, the default mark until they are in. A selected marker turns bright: its picture is drawn as its shape in the mark's ink (`Marker::ink`), as a glyph is.
- The camera's span stays within the drawn set's levels each frame; a bounded map zooms out until its bounds fit (its smallest level's tiles at an eighth at most) and the view stays inside them.
- `Tiles` drops the least recently drawn or needed, never what the last frame drew or needed or a load just brought. Whatever leaves `Tiles` or `Images` goes to `window.drop_image` (`stale`), in the window it was drawn in: `hide(window)` when a window stops showing a part.
- `Stage::mini` draws and zooms with the wheel: no other input, hover, chip or menu; its tile cache is small.
- A user's pin's pictures and clips (`UserPin::media`): its card shows one, a strip picks another or drops one (the file stays), ADD MEDIA picks files, a picture (a bitmap kept as PNG) or files pasted into its fields go to it, MOVE brings the original's picture and clip; all through `Board::attach` with a `Target` taken when asked (before a picker opens), which keeps them off the UI thread and adds them only while that map shows and the pin lives. The card holds the shown one by name and the list's pictures decoded small off the UI thread (`card::media::Kept`, made again when the list changes); only the lightbox decodes one in full, in a cache of its own.
- Clips: `ClipView` downloads a map pin's through `media::path` (a user's pin's is a file already), decodes with `video` on the window's D3D11 device, paints with `paint_surface` (never the atlas), and starts again when the device changed. A clip no frame asked for stops.
- Pin links: `PIN_LINK` selects a pin; only `http://` and `https://` open in the browser; any other link, `wemod:` included, does nothing.
- A closed map forgets its pins after 3 minutes (`forget_later`), unless a trainer is live in its game; `open` cancels that, and `forget_later` drops a load on its way before forgetting.
- Paint allocates nothing per pin or label: per-map data is made once (`Shown::of`, `Images`), markers regroup per half zoom step, regions and labels off the view are skipped.
- Ask for frames only while something moves (`animate`); a size change asks for one more.
- Anything laid over the stage calls `occlude()`: pins hover only while the stage's own hitbox is hovered.

## Traps
- The tracker keeps the heading for the whole run on the leaseholder's `Frame`; a lease with another frame starts it over.
- Tiles are decoded with a 1 px border: the atlas filters across an image's edge and shows seams otherwise.
- Closed, a board shows the tracker's last fix, not a live one; its bearing goes stale.
- Hidden regions are saved by `Region::id`, hidden groups by id. Titles an older build saved are `hidden_labels` until an install names them (`View::resolve`). The sidebar has one row per region name, shown while any part shows.
