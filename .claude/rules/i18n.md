# i18n

Texts the user reads, in their language: the `i18n` crate, the catalogs and how code names a message.

## Surface
- `Language` (`tag`, `name`), `LANGUAGES` (what we ship), `Language::system`, `Language::find`.
- `Catalog::new(language, pseudo, domains)` (each domain's language tags and Fluent sources, borrowed: it keeps its own copy), `text(domain, key, args)`; `Key`, `Arg`.
- In `shell`: `ui::text::Texts`, a global set by `Settings` with the registry's catalogs; `t(cx, key)`, `tf` (with arguments), `text` (a source's `Text`), `said` and `why` (a `Failure`), `failed` (a message whose `why` is one), `app_text`, `digits` (a number's marks), `content_locale` (what sources are asked in); `ui::key`, a const per message of `crates/shell/locales/en.ftl`, a file per UI area holding that area's `##` sections (`cheats.rs`: Cheats, Hotkeys, Trainer; `mod.rs`: Shared, Tray, Failures), ids prefixed by section (`cheats-`, `hotkeys-`).

## Rules
- A domain is a crate's `locales/<tag>.ftl`: `app` is `shell`'s; a source's is named by its `SourceId`. The remote panel's is `web/panel/locales` (its rules: `panel.md`), held to `LANGUAGES` by a test here: a new language ships there too.
- Code names a message only through a `Key("id")` const of its crate. `checks` holds every key to an English message, every English message to a key, every other language's messages to English ids (a translation may be partial), and parses every file.
- A text is written in its final case: no `to_uppercase` on our own text. Plurals and units are Fluent selectors, never `if n == 1`.
- A message is formatted once per language (`t`, `text`) or once per distinct arguments (`tf` keeps what it made), so a redraw formats nothing. A plain count is an `Arg::Num` (Fluent prints it as Rust does): building the arguments allocates nothing either; padded numbers are made in Rust, take the language's marks (`digits`: `number-group`, `number-decimal`) and come with their `count`, as a language's plural may need it.
- A missing message falls back to English; its key shows only when English lacks it too.
- A language whose script the UI font lacks gets a family that has it (`shell::ui::theme::ui_family`: `is_cyrillic`, `is_cjk`), and the window's root font names Chakra Petch (Latin and Thai) and the CJK family as `FontFallbacks` in every language (`Look`, made once per look): DirectWrite shapes a run with the one face it is given, so Thai or han in content or a mono field would otherwise take a family Windows picks.
- `IMPULSE_LOCALE=pseudo` in a debug build accents and stretches every message's own text: a cut or an English literal shows.
- `i18n` knows no GPUI and no crate of ours; Fluent types stay inside it.

## Traps
- Fluent's isolation marks are off: GPUI draws them as boxes.
- `gpui-component` keeps its own texts (input menus) in `rust-i18n`; `Settings` sets its locale too. It lacks French, German, Spanish, Polish, Turkish and Thai (its English shows) and has part of Italian.
